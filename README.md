# 🛍️ MERN E-Commerce Admin Dashboard

A modern **Admin Dashboard** for managing a full-stack MERN E-Commerce application.

This project provides an administrative interface for managing products, users, orders, payments, and other e-commerce operations.

# ✨ Features

## 📊 Admin Dashboard

- Admin dashboard
- Overview of e-commerce data
- Product management
- User management
- Order management
- Payment management
- Admin authentication
- Protected admin routes

## 📦 Product Management

- Add products
- View products
- Update products
- Delete products
- Manage product information
- Manage product inventory

## 👥 User Management

- View registered users
- Manage users
- Admin authorization
- User information management

## 🛒 Order Management

- View orders
- View order details
- Manage order status
- Track customer orders
- Order management through backend APIs

## 💳 Payment Management

- Razorpay payment integration
- Payment information
- Payment/order status
- Backend payment verification
